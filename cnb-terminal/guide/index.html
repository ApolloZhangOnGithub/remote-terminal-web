⚡ 脚本自动

1 · 本地安装并注册

在要接入的机器上跑一行，自动装好 ttyd/tmux、向中转服务器注册本机、分配唯一机器 ID、配好开机自启的隧道与终端。

curl -fsSL https://c-n-b.space/terminal/init.sh | bash
🔒 一次性

2 · 授予完全磁盘访问（仅 macOS）

macOS 隐私保护(TCC)会拦截访问 下载/文稿/桌面，远程时你点不到“允许”会卡死。授权一次，永不再弹。脚本会自动跳转到设置页。

系统设置 → 隐私与安全性 → 完全磁盘访问权限 → ＋ → 加入 ttyd → 打开开关。

🔒 一次性

3 · 代理加直连规则（若开了 Shadowrocket/Clash）

全局代理会把隧道流量绕到海外节点，导致严重卡顿。给中转服务器加一条直连规则，延迟立刻降到本地 SSH 同级。机器端和看终端的设备都要加。

IP-CIDR, <中转服务器IP>/32, DIRECT
🔒 一次性

4 · 关闭休眠（让机器长期可达）

笔记本插电、保持不合盖；macOS 一条命令永久禁用插电休眠。

sudo pmset -c sleep 0
🔒 首次

5 · GitHub 登录 → 选机器 → 进终端

回到本页点“用 GitHub 登录”，授权后看到你绑定的机器列表，点任意一台即进入它的网页终端。建议把本页添加到主屏幕。
