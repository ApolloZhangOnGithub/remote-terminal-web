# 网页终端平台 · 用户初始化指南

> 一句话：装好后，**任何浏览器打开一个网址、用 GitHub 登录、选一台你的机器，就进入它的终端**。无需 App、无需 VPN、无需在目标机开放任何入站端口。
>
> 本指南面向**每一位接入自己机器的用户**。下面标 🔒 的是**一次性**步骤，做完永久生效；标 ⚡ 的是平台/脚本**自动完成**、你无需操心的部分。

---

## 0. 它是怎么跑起来的（30 秒理解）

```
你的手机/任意浏览器
      │  https + wss（加密，可穿透代理）
      ▼
  中转服务器（你的云服务器，公网）
      │  SSH 反向隧道（你的机器主动拨出，不开入站端口）
      ▼
  你的机器（Mac/Linux）：ttyd 网页终端 → tmux → 你的程序（Claude Code 等）
```

- **ttyd**：把本机终端通过网页暴露出来的小服务 —— 你在浏览器里看到的“终端”。
- **SSH 反向隧道**：把本机 ttyd 安全地接到中转服务器，**全程不在你机器上开任何入站端口**。
- **tmux**：会话常驻 —— 断网、锁屏、换设备，程序都在原地继续跑，重连即恢复。

---

## 1. 🔒 本地安装（在你要接入的机器上，跑一次）

macOS：
```bash
brew install ttyd tmux
```
Linux：
```bash
sudo apt install -y tmux        # ttyd 用下方一键脚本装好的二进制
```
然后运行平台提供的初始化脚本（见 `scripts/init-local.sh`），它会 ⚡ 自动完成：
- 安装/校验 ttyd、tmux
- 用你的密钥向中转服务器注册本机，**自动分配一个唯一机器 ID 和隧道端口**
- 写好开机自启的隧道与终端服务（掉线自动重连）
- 配好防睡眠

---

## 2. 🔒 授予“完全磁盘访问权限”（仅 macOS，一次，永久）

**为什么必须做**：macOS 隐私保护(TCC)默认拦截程序访问 `下载/文稿/桌面`。不授权的话，每次访问都会弹窗——**而你在远程根本点不到“允许”，整个会卡死**。授权一次后永不再弹。

> macOS 的安全机制(SIP)决定了**没有任何脚本能代替这一步**，但**只需在机器前做这一次**。初始化脚本会自动帮你打开到正确的设置页。

1. 打开：**系统设置 → 隐私与安全性 → 完全磁盘访问权限**
   （脚本会自动跳转到这一页）
2. 点 **＋**，验证指纹/密码
3. 按 **⌘⇧G**，粘贴 ttyd 的路径并回车（脚本会打印你机器上的确切路径）
4. 选中 **ttyd**，打开右侧开关

✅ 完成后，终端里运行的一切（tmux、Claude Code…）访问任意目录都不再弹窗，远程畅通。

---

## 3. 🔒 如果你的机器开了代理（Shadowrocket / Clash / Surge / V2Ray）

**这一步直接决定流不流畅。** 这类代理多为全局(TUN)模式，会把你机器到中转服务器的隧道流量也劫持、绕到海外节点，导致每个按键来回上百毫秒、严重卡顿。

**修复：给中转服务器 IP 加一条“直连”规则。** 在代理的“规则”里加入：
```
IP-CIDR, <中转服务器IP>/32, DIRECT
```
- **接入的机器**和**你看终端用的手机/电脑**上的代理，**都要加**。
- 加完后隧道走直连，延迟降到与本地直连 SSH 同一量级。

> 自检：初始化脚本会测量隧道往返延迟。若 > 50ms 且你在国内同区域，基本就是这条规则没加。

---

## 4. 🔒 防止机器休眠（接入的机器要长期可达）

- 笔记本：**插电源**；macOS 还需 `系统设置 → 电池 → 选项 → 显示器关闭时防止睡眠`，并保持不合盖（或外接显示器）。
- 一劳永逸（macOS，插电时永不睡眠）：
  ```bash
  sudo pmset -c sleep 0
  ```
  （脚本会引导执行；这是唯一需要 sudo 的一步。）

---

## 5. GitHub 登录（首次）

1. 浏览器打开平台地址：`https://<主域名>/terminal`
2. 点 **用 GitHub 登录** → 授权
3. 登录后看到**你绑定的机器列表**，点任意一台 → 进入它的网页终端
4. 终端支持**多开**：多开几个标签页 = 多个互不干扰的独立终端

> 平台用 GitHub 身份做隔离：你只能看到、进入**你自己绑定**的机器。

---

## 6. 日常使用

- 打开 `https://<主域名>/terminal` → 选机器 → 用。
- 断线、锁屏、换网络都不怕：tmux 会话常驻，重新打开网页即恢复，程序一直在跑。
- 建议把页面 **添加到主屏幕**，像 App 一样一键进入。

---

## 7. 出问题自检（接入的机器上）

```bash
remote-doctor
```
一条命令体检整条链路（隧道 / 终端 / 延迟 / 电源 / 工具），能自动修的自动修，修不了的给出确切命令。
